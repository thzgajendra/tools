Free Email Extractor

Paste text, an HTML page source, a CSV or a log. The tool finds every email address, lowercases it, removes duplicates and sorts the list. Runs in your browser: nothing is sent anywhere. Use it only on lists you are allowed to process.

Next step: check the extracted list for typos, disposable and role addresses with the free email list checker (small lists), or run big lists (thousands of rows) with the Email List Checker on Apify. Also: CSV cleaner | JSON to CSV.

FAQ

Is my text uploaded? No. Processing is local JavaScript.

What counts as an email? The pattern local@domain.tld with common characters. It finds candidates; it does not prove a mailbox exists. Use the checker for validation.

Does it handle obfuscated emails (name [at] site [dot] com)? No, only normal addresses.
