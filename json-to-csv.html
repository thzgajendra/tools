Paste a JSON array of objects (or a single object). Nested keys are flattened (user.name); arrays are written as JSON text. Runs in your browser: nothing is sent anywhere.

FAQ

Is my data uploaded? No. Processing is local JavaScript.

How are nested objects handled? Flattened with dots. Columns are the union of all keys, in first-seen order. Arrays become JSON text in one cell.

Excel opens it wrongly? The download includes a UTF-8 BOM so accents and non-Latin text display correctly.
