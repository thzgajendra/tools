Free Sitemap XML to URL List / CSV

Open a site's /sitemap.xml in your browser, select all, copy, and paste the XML below. You get one URL per line (or a CSV with lastmod). Duplicates are removed. If the file is a sitemap index, the child sitemap links are listed so you can open them one by one. Runs in your browser: nothing is uploaded.

FAQ

Is my XML uploaded? No. Processing is local JavaScript.

Why paste instead of entering a URL? Browsers block reading other sites' files from a web page (CORS), so the paste step keeps this tool private and serverless.

Does it read .xml.gz sitemaps? Not here; unzip first or use the Apify actor.
